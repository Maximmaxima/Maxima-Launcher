# Privacy Policy

## Maxima Launcher

Maxima Launcher is an unofficial community-developed launcher and mod manager for Minecraft: Java Edition.

This document explains what information Maxima Launcher uses and how authentication data is handled.

## Microsoft Account Authentication

Maxima Launcher uses Microsoft's official OAuth 2.0 authentication system with Authorization Code Flow and PKCE.

Users sign in directly through Microsoft's official login page.

Maxima Launcher does not:

- ask for or store Microsoft passwords
- embed or store a Microsoft client secret
- receive the user's Microsoft password
- sell authentication or account information
- share authentication tokens with third parties

## Authentication Tokens

Authentication tokens may be used to communicate with:

- Microsoft Identity Platform
- Xbox Live
- XSTS
- Minecraft Java Game Services

Tokens are used only for features requested by the signed-in user.

At the current development stage, authentication tokens are stored only in memory for the active launcher session and are not permanently stored by Maxima Launcher.

Closing the launcher removes the active session tokens from memory.

## Minecraft Account Data

After successful authentication, Maxima Launcher may access information provided by Minecraft Java Game Services, including:

- Minecraft username
- Minecraft UUID
- Minecraft: Java Edition ownership status
- Minecraft Java profile information
- the user's own Minecraft Java skin

This information is used only to provide launcher functionality.

## Skin Management

If the user chooses to change their Minecraft skin, Maxima Launcher may upload a skin selected by the user to their own authenticated Minecraft Java profile.

Maxima Launcher does not modify another user's Minecraft account or skin.

## Local Data

Maxima Launcher stores launcher-related data locally on the user's computer.

This may include:

- launcher settings
- Minecraft profile configurations
- installed mods
- resource packs
- shaders
- modpack metadata
- locally imported skins
- cached project icons

This information is not automatically uploaded to Maxima Launcher or to a Maxima-operated server.

## Modrinth

Maxima Launcher uses the Modrinth API for features such as:

- discovering mods
- downloading mods
- downloading modpacks
- checking for updates
- retrieving project information

Requests made to Modrinth are subject to Modrinth's own privacy policies and terms.

## Data Collection

Maxima Launcher currently does not operate an analytics or telemetry service.

The launcher does not intentionally collect personal information on an external Maxima Launcher server.

## Third-Party Services

Maxima Launcher interacts with third-party services including Microsoft, Xbox, Minecraft and Modrinth.

Those services may process data according to their own privacy policies and terms.

## Security

Users should only download Maxima Launcher from sources they trust.

Never enter a Microsoft password directly into Maxima Launcher. Microsoft account authentication should always take place on Microsoft's official authentication pages.

## Changes

This privacy policy may be updated as Maxima Launcher continues development.
